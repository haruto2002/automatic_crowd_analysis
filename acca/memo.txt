# localでのaiaccel実行例

## Detction
pixi run aiaccel-job local --config=abci3.yaml gpu --n_tasks=49 --n_tasks_per_proc=1 outputs_aiccel/logs/202408_Yokohama_WorldPorters/detection/aiaccel.log -- python run_detection.py video_dir=/groups/gaa50073/nakayama-haruto/hanabi_videos/202408_Yokohama_WorldPorters output_dir=outputs_aiccel/202408_Yokohama_WorldPorters video_extension=MOV

## Tracking（これでインタラクティブでcpu並列できるはず）
pixi run aiaccel-job local --config=abci3.yaml cpu --n_tasks=49 --n_tasks_per_proc=1 outputs_aiccel/logs/202408_Yokohama_WorldPorters/tracking/aiaccel.log -- python run_tracking.py results_root_dir=outputs_aiccel/202408_Yokohama_WorldPorters
